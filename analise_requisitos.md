**Análise de Requisitos - Sistema de Gestão de Estoque PetShop (PetManager)**

O sistema PetManager tem como intuito de facilitar a gestão de estoque para PetShop de produtos como medicamentos veterinários, brinquedos, rações, produtos de higiene.
O sistema terá controle de entrada/saída de produtos, controle de estoque mínimo, que emite alertas com históricos das ações dos usuários.

*Requisitos Funcionais:*
- Tela de login (para usuários com permissão);
- Sistema de cadastro de diversos produtos;
- Controle de Entrada e Saída;
- Sistema de Estoque Mínimo (com emissao de alertas)

*Requisitos Não Funcionais:*
- Estilização Simples (CSS Vanilla);
- Separação entre formularios e tabelas;
